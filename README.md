# Minecraft Builder Portfolio

Portafolio estático listo para GitHub Pages.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño responsive, animaciones y efectos.
- `script.js` — animaciones de entrada, cursor y navegación.
- `assets/` — imágenes de los proyectos.

## Publicarlo gratis con GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.

## Antes de publicar
En `index.html`, cambia:
`tu-correo@ejemplo.com`
por tu correo real.

También puedes cambiar los textos, títulos y etiquetas directamente en `index.html`.
